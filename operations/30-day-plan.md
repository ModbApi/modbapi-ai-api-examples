# 30 天执行排期

排期以“先打通链路，再扩展内容，最后用深层转化复盘”为顺序。每天保留变更记录和事件数据，避免同一周同时改动代码、落地页和广告受众。

## 第 1 周：基础链路

| 天数 | 工作 | 验收 |
| --- | --- | --- |
| Day 1 | 复核 `/douyin` 首屏、注册和首次调用路径 | 手机网络可访问，核心 CTA 可点击 |
| Day 2 | 检查 UTM 捕获、首次/最后来源和服务端事件 | `landing_page_view`、`registration_success` 可回溯 |
| Day 3 | 发布 Python 示例和 README 回链 | 干净 Python 3.10/3.12 环境收到 2xx |
| Day 4 | 录制 Python 教程并做无敏感信息审查 | 视频、评论区和 UTM 一一对应 |
| Day 5 | 小范围邀请测试 | 完成注册 -> Key -> 首次成功调用 |
| Day 6-7 | 修复阻塞问题，建立第一版日报 | 有访问、注册、激活基线 |
